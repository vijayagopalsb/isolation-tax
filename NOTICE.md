INTELLECTUAL PROPERTY NOTICE
----------------------------

The conceptual framework presented in this repository is original work:

1. **"Lateral Isolation"** — the architectural constraint preventing direct peer-to-peer communication between services/modules.

2. **"The Enforcement Gap"** — the identification that existing patterns (Facade, Mediator, API Gateway, ESB) describe intended communication paths but do not enforce them.

3. **The Decision Framework** — criteria for when to enforce vs. skip lateral isolation.

4. **The Dual Enforcement Mechanism** — combining build-time (ArchUnit) and runtime (AOP) enforcement.
