## About This Work

The Lateral Isolation framework presented in this repository is original work first published on **20 July 2026**. 

It addresses:

- The gap between architectural intent and implementation reality
- Why existing patterns (Facade, Mediator, API Gateway, ESB) describe isolation but don't enforce it
- A decision framework for when to enforce vs. skip lateral isolation
- Automated enforcement via ArchUnit (build-time) and AOP (runtime)
